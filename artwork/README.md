# Artwork source

`icon.svg` is the source for the integration's icon (the "cloud hub": Sigenergy's
cloud linked to a Smart Port load, the battery and an EV charger).

The PNGs Home Assistant uses live in `custom_components/sigen_smartport/brand/`:

| File | Size | Notes |
|---|---|---|
| `icon.png` / `icon@2x.png` | 256 / 512 px | Rendered from `icon.svg` |
| `dark_icon.png` / `dark_icon@2x.png` | 256 / 512 px | Same as the icon; the tile works on dark backgrounds |
| `logo.png` / `logo@2x.png` | 256 / 512 px high | Icon plus "Sigenergy / Cloud Control" in Outfit (Google Fonts, OFL), dark text |
| `dark_logo.png` / `dark_logo@2x.png` | 256 / 512 px high | Same with light text |

All have transparent backgrounds. Colours: gradient `#14b8a6` → `#4338ca`,
wordmark `#1f2733` / `#3d4a5c` (light) and `#ffffff` / `#d5dbe3` (dark).
